# APOSIRA updated documentation pack

Version 1.0 — 4 November 2026. Proposed baseline for review, not a declaration of stakeholder approval.

Read in order:
1. Product Requirements — goals, scope, release priorities and decisions.
2. Software Requirements — AP-01 through AP-32, NFR-01 through NFR-08, acceptance criteria and source reconciliations.
3. System Design — current modules, schema, interfaces, data flows and production boundaries.
4. Use Cases and Workflows — actors, transaction paths, fulfillment state machine and exception handling.
5. Verification and Traceability — original G1/G2 mappings, initial-report coverage, tests and release gates.
6. Deployment and Operations — local/RunPod setup, private GitHub access, troubleshooting, backup and recovery.

DOCX files are the review deliverables; matching Markdown files and requirements-register.json support future maintenance. Original reports are unchanged. The local reorganized working tree was inspected without committing or altering its staged changes. The pack has not been pushed or published.

Sources: Final Year Project G1.docx; Final Project Report G2.docx; Initial Report (FYP - II).docx, all supplied in Downloads. See source identifiers and sections in the SRS and verification document. The marketing website is not treated as evidence of implemented functionality. No credentials from the conversation are included.

Verification baseline: 12 root tests passed on 4 November 2026 with one dependency deprecation warning. Performance, capacity, security and legal compliance targets are not certified by that test result.
